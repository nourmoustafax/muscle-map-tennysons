### Parsing and transformations

`scripts/acquire_data.py` checks the original SHA-256 digests. `scripts/prepare_data.py` reads CSV with BOM-aware decoding, retains original participant/group/row references, parses numeric values and retains literal `NA` as `null`. `PRE_TEST` day 6 maps to study day −6; in-test days retain their reported day; post-test day 3 maps to study day 73, after the 70-day bed-rest period. These are documented study coordinates, not invented calendar dates or live mission days. Original phase/day fields can be reproduced from the source row in the byte-preserved file.

Method, measured right-sided region, unit basis and source identity are attached from the verified file definitions. The four quadriceps atlas members represent one group measurement, not four independent measurements. A gastrocnemius value represents the right medial gastrocnemius region only.

### Eligibility and calculations

The personal review adapter (`src/personal-review.ts`) and existing deterministic science engine preserve person/mode/namespace isolation and exact region/side/quantity/unit/method/protocol/site comparisons. The source's explicitly flagged baseline is pinned to its observation ID; personal references are chosen explicitly, including a unique valid user-declared import reference. A new record or filter does not silently change it. Missing, undated, zero/invalid-reference and future-cutoff cases do not gain fabricated dates or percentages.

Baseline change is `(current − baseline) / baseline × 100`. Previous-assessment change uses the previous compatible observation independently. For participant **7326**, quadriceps panoramic ultrasound at **BR69** is **87.95 cm²**, source ID **62**; the **BR−6** reference is **84.53 cm²**, ID **53**; the previous **BR53** result is **88.3 cm²**, ID **61**. Independent Decimal arithmetic yields **+4.045900863598722…%** from baseline and **−0.396375990939977…%** from the previous result. Thus above baseline does not mean no recent decline.

Historical cut-offs exclude later observations from the displayed assessment/calculation. Missing markers and broken lines remain visible; line segments are guides between observations, not continuous sensing. Personal date-only input stays day-precision; correction preserves an existing exact timestamp only when its original examination date is unchanged.
